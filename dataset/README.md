# Compiled Analysis Results from All Tests

## Overview
This dataset contains the output of the **ClarityLoop AI Engine** processed against open-source GitHub data (specifically the Pandas and Kubernetes repository). The goal of this research (Project CollabSense) was to evaluate if an AI Agent tuned to analyse enterprise environments could identify **Strengths**, **Growth Opportunities**, and **Sentiment Patterns** in open-source repositories.

The data has been anonymized (using Faker) and structured into three primary CSV files representing different layers of the AI's analysis.

## File Structure

### 1. `growth_opportunities.csv` (The Signal)
Contains specific constructive advice generated by the AI for specific users.
*   **Use case:** Analyzing the "quality" and "topic" of the AI's coaching advice.
*   **Volume:** Variable per seed (e.g., "Noisy" seeds generated 1000+ rows; "Dense" seeds generated <20).

### 2. `strengths.csv` (The Positive Reinforcement)
Contains positive traits and behaviors identified by the AI.
*   **Use case:** Analyzing what the AI considers "good behavior" in open-source code reviews.

### 3. `feedback_scores.csv` (The Raw Sentiment)
Contains the sentiment score (0-10) assigned to every single comment analyzed.
*   **Use case:** Statistical analysis of sentiment distribution, detection of "grumpiness," or identifying bias.

---

## Data Dictionary & Schema

All three files share a common schema to allow for easy merging and cross-referencing.

| Column Field | Description |
| :--- | :--- |
| **`seed_id` / `sender_seed`** | The ID of the experimental run (see *Experiment Keys* below). |
| **`email` / `user_email`** | The anonymized email of the user receiving the analysis. |
| **`title`** | *(Growth/Strength only)* The specific advice or trait title generated by the AI. |
| **`sentiment_score`** | Integer (0-10). The AI's judgement of the tone. (0=Negative, 10=Positive). |
| **`content`** | The **Raw Evidence**. The actual text of the GitHub comment/PR that triggered this analysis. |
| **`link`** | The URL to the specific GitHub comment or PR context. |
| **`Source_Directory`** | The batch folder origin (useful for tracing back to specific test runs). |

---

## Experiment Keys (The "Seeds")

The dataset represents a variety of AI configuration strategies, ranging from "High Precision/Safe" personas to "Radical Candor/High Volume" settings, as well as specific stress tests on dense contributor graphs (Kubernetes). To isolate specific runs, combine the **Seed ID** (e.g., `4`, `5`, `6`, `7`, `8`) with the **Source_Directory**.

**Note:** A future report will be released providing a detailed mapping of these identifiers to their specific experimental parameters, and these CSVs may be updated to reflect cleaner labeling in the future.

## How to Link the Data

The dataset is relational. You can link rows across files using the **Evidence**:

1.  **`content` + `link`**: These are the unique identifiers of the raw event.
2.  **`feedback_scores.csv`** is the "Master List" of all analyzed events.
3.  **`growth_opportunities.csv`** and **`strengths.csv`** are **subsets** of that master list where the AI decided the content was significant enough to warrant specific advice.

## Usage Notes
1.  **Anonymization:** User names and emails are generated via Faker. However, the `content` and `link` fields point to real, public GitHub data.
2.  **Missing Context:** A small percentage (<4%) of rows may have missing `content` text due to the original comments being deleted or moderated on GitHub between analysis and extraction.
3.  **Score Range:** Sentiment scores are strictly integers between 0 and 10.
